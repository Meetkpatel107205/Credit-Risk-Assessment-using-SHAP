# 💳 Explainable Credit Risk Assessment

A machine learning web application that predicts **credit risk** and provides **SHAP-based explanations** to understand the key factors influencing each prediction.

## 🌐 Live Demo

https://credit-risk-assessment-using-shap.onrender.com

## ✨ Features

* 💳 Credit risk prediction
* 📊 Risk probability estimation
* 🤖 Logistic Regression and XGBoost models
* ⚙️ Scikit-learn preprocessing pipelines
* 🎯 Hyperparameter tuning
* 📈 Cross-validation and model evaluation
* 🧠 SHAP-based model explainability
* ⚡ FastAPI REST API
* 🌐 HTML, CSS & JavaScript frontend
* 🚀 Deployed on Render

## 🛠️ Tech Stack

* **ML:** Python, Scikit-learn, XGBoost
* **Data Processing:** Pandas, NumPy
* **Explainability:** SHAP
* **Model Persistence:** Joblib
* **Backend:** FastAPI, Uvicorn
* **Frontend:** HTML, CSS, JavaScript
* **Deployment:** Render

## 🧠 Explainable AI

**SHAP (SHapley Additive exPlanations)** is used to explain model predictions by identifying how individual features contribute to the final credit risk prediction.

The project provides both:

* **Global explanations** — overall feature importance
* **Local explanations** — factors influencing an individual prediction
